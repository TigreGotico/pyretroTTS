# Architecture

## Module map (C -> Python)

| C file | Python module | Contents |
|---|---|---|
| `mt4.h`, `Fsynth.h`, `SpeechEqu.h` | `lintalker/_consts.py` | Constants, fixed-point math helpers (`mMul2`, `mDiv`, `clamp`, ...) |
| `mt4.h` phoneme enum | `lintalker/_phonemes.py` | Phoneme ids, names, categories |
| `Data.c` | `lintalker/_data.py` | Voice definitions, coefficient tables (generated by `tools/extract_data.py`) |
| `Say.c`, `formantSynth.c`, `BackEnd.c` | `lintalker/_backend.py` | Frame-by-frame formant synthesis: `say_frame`, `e_fill_next_frame`, `head_rules`/`tail_rules`, ramp/pitch handling |
| `EngToP.c` | `lintalker/_engtop.py` | English word -> phoneme dispatch (in progress) |
| `Engine.c` | `lintalker/_engine.py` | Top-level init/speak/reset API (in progress) |
| `EmbeddedCmd.c` | not ported | Embedded control codes (`\`Genxx` etc.); `DoCtrl`/`DoNote` in `_backend.py` are stubs |
| `FrontEnd.c`, `Morph.c` | not ported | Text normalization, tokenization, morphology |
| `english_lex.c`/`English.lex` | not ported | Binary pronunciation dictionary + lookup |
| `Sounds.c` | not ported | Embedded sound effects (bells, etc.) — raw PCM blobs, not logic |

Fixed-point arithmetic mirrors the C reference's `kPrecision=13` scheme;
`_backend.py`'s helpers (`mMul2`, `mDiv`, `mScale`, `mUnScale`, `rshort`,
`clip14`) exist to keep intermediate values numerically identical to the
16-bit/32-bit fixed-point math the C code relies on. Where the C code leans
on 16-bit integer wraparound implicitly (`rShort`-typed locals in `Say.c`),
the Python port truncates explicitly with `rshort()` — this is applied at
known-critical points but has not been audited call-site-by-call-site; see
the correctness caveat below.

## Correctness verification

`test/test_voices.py` is the only test in this repo that can catch a DSP
regression. It:

1. Shells out to a compiled build of the C reference (`lintalker-c/bin/Debug/test_harness`)
   for a given voice + input text, capturing the phoneme plan it derives
   and its per-frame synthesis state (pitch, amplitude, formants, markers).
2. Feeds the identical phoneme plan through the Python backend
   (`lintalker.api.synthesize_phonemes` / the lower-level calls it wraps).
3. Diffs per-frame values exactly.

As of the last full run (`pytest test/test_voices.py --all` equivalent),
the 8 stock voices (Fred, Kathy, Princess, Junior, Ralph, Whisper, Zarvox,
Trinoids) match bit-exactly. The 9 special-effect voices (Bubbles, Boing,
Bells, Hysterical, Deranged, GoodNews, BadNews, PipeOrgan, Cellos) still
show pitch-curve mismatches under investigation — see the repo's issue
tracker / recent commits for the current state, since this is actively
being worked.

To run this test locally you need `lintalker-c` checked out and built as a
sibling directory (`../lintalker-c` relative to this repo) with its
`test_harness` target built (see its `Makefile`).

`test/test_pipeline.py` and `test/compare_all.py` are smoke tests over
hand-captured reference constants; they don't do differential testing
against a live C run and won't catch a regression that stays in a
plausible numeric range.

## Known gaps

- No English text-to-phoneme frontend — `DectalkTTS.get_tts()` (the OVOS
  plugin entry point) raises `NotImplementedError` for now.
- `DoCtrl`/`DoNote`/`DoNoteScript` (embedded commands, note-driven singing)
  are unported stubs.
- 16-bit wraparound truncation inside the `say_frame` hot loop is not
  exhaustively verified against extreme/out-of-range voice parameters.
