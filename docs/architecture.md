# Architecture

## Module map (C -> Python)

| C file | Python module | Contents |
|---|---|---|
| `mt4.h`, `Fsynth.h`, `SpeechEqu.h` | `lintalker/_consts.py` | Constants, fixed-point math helpers (`mMul2`, `mDiv`, `clamp`, ...) |
| `mt4.h` phoneme enum | `lintalker/_phonemes.py` | Phoneme ids, names, categories |
| `Data.c` | `lintalker/_data.py` | Voice definitions, coefficient tables (generated by `tools/extract_data.py`) |
| `Say.c`, `formantSynth.c`, `BackEnd.c` | `lintalker/_backend.py` | Frame-by-frame formant synthesis: `say_frame`, `e_fill_next_frame`, `head_rules`/`tail_rules`, ramp/pitch handling, `do_note`/`do_note_script` (embedded note-driven pitch) |
| `EngToP.c` | `lintalker/_engtop.py` | English word -> phoneme dispatch via letter-to-sound rules. Operates on a single pre-isolated, already-uppercased word (see `test/test_engtop.py`). |
| `FrontEnd.c` (tokenizer + per-word dispatch only) | `lintalker/_frontend.py` | Splits text into words + end-of-word punctuation, calls `_engtop.engtop()` per word. Does not assemble a `(phonemes, ctrls, durs)` plan — see "Known gaps". |
| `Engine.c` | `lintalker/_engine.py` | Top-level init/speak/reset/rate/pitch/volume API, built on `_backend.py`. `e_speak_buffer` (the text-in entry point) and a few fsynth-dependent setters (`e_reset_params`, `e_use_voice`, `e_reinit_voice`) raise `NotImplementedError` naming the specific unported upstream C function they need. |
| `EmbeddedCmd.c` | partially ported | `DoNote`/`DoNoteScript` (embedded note-driven singing, used by GoodNews/BadNews/PipeOrgan/Cellos) are ported into `_backend.py`. General embedded control codes (`` `Genxx `` etc., `DoCtrl`) remain a stub. |
| `FrontEnd.c`, `Morph.c` | not ported | Text normalization, tokenization, morphology |
| `english_lex.c`/`English.lex` | not ported | Binary pronunciation dictionary + lookup |
| `Sounds.c` | not ported | Embedded sound effects (bells, etc.) — raw PCM blobs, not logic |

Fixed-point arithmetic mirrors the C reference's `kPrecision=13` scheme;
`_backend.py`'s helpers (`mMul2`, `mDiv`, `mScale`, `mUnScale`, `rshort`,
`clip14`) keep intermediate values numerically identical to the 16-bit/32-bit
fixed-point math the C code relies on. Where the C code leans on 16-bit
integer wraparound implicitly (`rShort`-typed locals in `Say.c`), the Python
port truncates explicitly with `rshort()`/`s16()` at known-critical points;
this has not been audited call-site-by-call-site.

## Correctness verification

`test/test_voices.py` is the test in this repo that catches DSP regressions.
It shells out to a compiled build of the C reference
(`lintalker-c/bin/Debug/test_harness`) for a given voice + input text,
captures the phoneme plan it derives and its per-frame synthesis state
(pitch, amplitude, formants, markers), feeds the identical phoneme plan
through the Python backend, and diffs per-frame values exactly.

Run it with `python3 test/test_voices.py --all` (needs `lintalker-c` checked
out and built as a sibling directory, `../lintalker-c`, with its
`test_harness` target built — see its `Makefile`).

`test/test_engtop.py` validates the `EngToP.c` letter-to-sound port the same
way, against a standalone build of `EngToP()` isolated from the rest of the
engine.

`test/test_pipeline.py` and `test/compare_all.py` are smoke tests over
hand-captured reference constants; they don't do differential testing
against a live C run and won't catch a regression that stays in a
plausible numeric range.

## Known gaps

- `lintalker/_frontend.py` tokenizes text and dispatches each word through
  `_engtop.engtop()`, but there is no bridge from that per-word phoneme
  opcode list to the `(phonemes, ctrls, durs)` shape
  `api.synthesize_phonemes` consumes. In the C reference that assembly
  (syllable/stress placement, duration, pitch contour) lives in
  `Fill_Phon_Buf_2`, `MarkSyllable`/`MarkSyllableStart`,
  `Place_Stress_In_Consonant`, `Mod_Duration`, and `Pitch_RaiseAndFall`
  (all in `BackEnd.c`, driven by `Collect_FE_Tokens`/`ParseSentence`) —
  none of which are ported. This is the remaining blocker for a real
  text-to-speech entry point; `api.synthesize_text()` does not exist yet.
- No pronunciation-exception dictionary lookup (`english_lex` not ported)
  — words fall through to letter-to-sound rules only.
- `Morph.c` (prefix/suffix stripping, compound-word handling) not ported.
- General embedded control codes (`DoCtrl`) are a stub; `DoNote`/
  `DoNoteScript` (note-driven singing) are ported.
- Bells/Hysterical (`kUseSyncSnd` voices) show a few residual `marker`
  field mismatches in `test/test_voices.py`: their marker buffer is
  populated from an external sample-audio file header in the C reference
  (`InsertSample`, `Say.c`) that isn't part of this port.
- 16-bit wraparound truncation inside the `say_frame` hot loop is not
  exhaustively verified against extreme/out-of-range voice parameters.
