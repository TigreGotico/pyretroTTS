# lintalker

A Python port of the classic DECtalk speech synthesizer.

This package has no OVOS/plugin dependencies — it is a standalone
synthesizer library. An OVOS TTS plugin wrapper around it lives in a
separate repo.

The C reference source this is ported from lives at
[dectalk/lintalker](https://github.com/dectalk/lintalker) (this repo's C
counterpart is checked out locally as `lintalker-c`).

## Status

| Layer | C reference | Status |
|---|---|---|
| Formant synthesizer (phonemes -> 16-bit PCM) | `Say.c`, `formantSynth.c`, `BackEnd.c` | Ported; 64/68 voice×text regression cases bit-exact against the C reference (`test/test_voices.py`); remaining 4 are a known Bells/Hysterical marker-data gap (external sample file, not ported) |
| Voice/data tables | `Data.c` | Ported (`lintalker/_data.py`, generated by `tools/extract_data.py`) |
| Note-driven singing (GoodNews/BadNews/PipeOrgan/Cellos pitch curves) | `BackEnd.c` (`DoNote`/`DoNoteScript`) | Ported, bit-exact |
| Per-phoneme control-queue dispatch (pitch/volume/mod overrides) | `BackEnd.c` (`DoCtrl`) | Ported, verified (`test/test_embeddedcmd.py`) |
| Backtick-escape text commands (e.g. `` `p200` ``) | `EmbeddedCmd.c` | Not ported — depends on the unported `FrontEnd.c` tokenizer |
| English word -> phoneme dispatch (single word, letter-to-sound rules) | `EngToP.c` | Ported, verified bit-exact for 36/36 test words (`test/test_engtop.py`) |
| Top-level engine API (init/speak/rate/pitch/volume) | `Engine.c` | Ported for everything not depending on unported text tokenization; see `docs/architecture.md` for the exact list of stubs |
| Text tokenization + per-word dispatch | `FrontEnd.c` (partial) | Ported (`lintalker/_frontend.py`): splits text into words + punctuation, dispatches each through `EngToP`. Does not assemble a synthesizable phoneme plan — see `docs/architecture.md` |
| Sentence-level stress/word/punctuation/syllable bookkeeping | `BackEnd.c` (`Collect_FE_Tokens` + `Flag_PhonBuf_1`/`MarkSyllable`/`MarkSyllableStart`) | Ported (`lintalker/_assembly.py`), verified bit-exact against the C reference for 4 sentences (`test/test_assembly.py`) |
| Allophone selection + plosive release (dark L, R-coloring, flapping, glottalization, ...) | `BackEnd.c` (`Fill_Phon_Buf_2`), `formantSynth.c` (`Insert_Closure_Release`) | Ported (`lintalker/_phonbuf2.py`), verified bit-exact against the C reference across voices/sentences (`test/test_phonbuf2.py`) |
| Per-phoneme duration assignment | `BackEnd.c` (`Mod_Duration`) | Ported (`lintalker/_moduration.py`), verified bit-exact against the C reference across voices/sentences (`test/test_phonbuf2.py`) |
| Pitch-contour assembly into a synthesizable phoneme plan | `BackEnd.c` (`Pitch_RaiseAndFall`/`Fill_Pitch_Buf`) | Not ported — the remaining blocker to a real `synthesize_text()` |
| Pronunciation dictionary lookup | `english_lex.c`/`English.lex` | Ported (`lintalker/_lexicon.py`), verified bit-exact for 249 test words (`test/test_lexicon.py`) |
| Morphology (prefix/suffix stripping, compounds) | `Morph.c` | Not ported |

**What this means today:** you can synthesize audio from an already-built
phoneme plan via `lintalker.api.synthesize_phonemes()`, and you can turn a
single, pre-isolated English word into a phoneme opcode list via
`lintalker._engtop.engtop()`, or tokenize a full sentence into per-word
phoneme opcodes via `lintalker._frontend`. There is no end-to-end
`synthesize_text()` yet — see `docs/architecture.md` for exactly what's
missing to close that gap.

## Install

```bash
uv pip install lintalker
```

## Usage

```python
from lintalker.api import synthesize_phonemes, pcm_to_wav
from lintalker._data import Fred_Voice

# a phoneme plan for "hi" (see lintalker/_phonemes.py for phoneme ids)
phonemes = [23, 11, 54, 3, 33, 22, 23]
ctrls = [1, 268500993, 0, 268502089, 9, 16393, 2621440]
durs = [1, 26, 10, 54, 23, 5, 135]

pcm = synthesize_phonemes(Fred_Voice, phonemes, ctrls, durs)
pcm_to_wav(pcm, "out.wav")
```

See `examples/` for more, and `docs/architecture.md` for how the port maps
to the C source.

## Voices

Fred, Kathy, Princess, Junior, Ralph, Whisper, Zarvox, Trinoids, Bubbles,
Boing, Deranged, GoodNews, BadNews, PipeOrgan, Cellos — all bit-exact
against the C reference. Bells and Hysterical have a few residual
marker-field mismatches from an unported external sample-audio dependency
(see `docs/architecture.md`).

## Testing

```bash
uv pip install -e .[test]
pytest test/
```

`test/test_voices.py` is the correctness backstop: it shells out to a
compiled build of the C reference (`lintalker-c`) and compares its
per-frame synthesis state and audio output against the Python backend,
voice by voice. It needs a local checkout+build of `lintalker-c` to run
(see `docs/architecture.md`).
